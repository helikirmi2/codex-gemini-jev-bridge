# Gemini + Jev Bridge for Codex

[English](README.md) | [Русский](README.ru.md)

Локальный MCP-сервер: Codex передаёт Gemini содержательные рутинные задачи по подготовке текстов, анализу и предложениям кода. TypeSafe Jev проверяет черновик по заданным критериям. Codex планирует работу, проверяет и применяет изменения, выполняет тесты и даёт итоговый ответ.

**Gemini использует включённую квоту подписки Google AI Pro через Antigravity CLI.** Мост требует `useG1Credits=false`: при исчерпании квоты работа Gemini останавливается до её обновления. Gemini API-ключ, оплата API, расход дополнительных кредитов и платный запасной маршрут не используются. Доступные модели и лимиты зависят от Google-аккаунта и [текущих условий Google](https://www.antigravity.google/docs/plans).

**Jev использует отдельный аккаунт, API-ключ и квоты TypeSafe.** Он не входит в Google AI Pro. Это независимый проект, не связанный с Google, OpenAI или TypeSafe.

## Быстрый запуск

Нужны Node.js 22+, npm, Codex с поддержкой локального MCP, [Antigravity CLI](https://www.antigravity.google/docs/cli/install/) с входом в аккаунт Google AI Pro и ключ TypeSafe. Команды ниже рассчитаны на Windows/PowerShell; живой доступ к сервисам на macOS/Linux в этой версии не проверен.

В папке репозитория:

```powershell
npm.cmd ci --ignore-scripts
node setup.mjs
```

Отредактируйте созданный `settings.json`: выберите доступную модель Gemini Flash из `agy models`, укажите путь к CLI и разрешите в `sourceRoots` только нужные проекты. Сохраните ключ TypeSafe отдельно в `.secrets/TYPESAFE_API_KEY`. Затем:

```powershell
npm.cmd test
node smoke.mjs --local-only
node install.mjs
```

Просмотрите план установки перед применением:

```powershell
node install.mjs --apply
```

Установщик регистрирует MCP, добавляет правила делегирования и ограничивает **глобальный профиль Antigravity CLI**, включая ручные сессии. Существующие файлы сохраняются в резервных копиях. Точные изменения и удаление описаны в [инструкции пользователя](docs/USER_GUIDE.ru.md). После применения перезапустите Codex.

## Инструменты MCP

| Инструмент | Назначение |
| --- | --- |
| `delegate_task` | Gemini готовит текст или патч, Jev проверяет 1–6 критериев; результат сохраняется локально |
| `jev_evaluate` | До 12 компактных вопросов для выбора, ранжирования и проверки доказательств за запрос |
| `bridge_status` | Локальный статус настроек без обращения к сервисам |

Сервисам передаются только текст задания и явно выбранные файлы. Ключи, локальные настройки и результаты исключены из Git. Перед выбором файлов прочитайте [границы доступа к данным](SECURITY.md) и [правила делегирования](docs/DELEGATION.md). Оценки Jev не заменяют проверку и тесты. Постановка задачи и проверка результата остаются за Codex; фиксированная экономия лимита не гарантируется.

## Быстродействие

Выбирайте строки через `source_selections`, передавайте Jev короткий `review_context` и привязанные `review_evidence`; по умолчанию ответ компактный. Успешные точные запросы кэшируются в памяти на 10 минут. Одинаковые одновременные задачи Gemini используют один запуск, разные получают ошибку занятости. Полные черновики и проверки сохраняются локально вместе с замерами времени и фактических обращений. См. [инструкцию по быстродействию](docs/PERFORMANCE.ru.md).

## Проверки

```powershell
npm.cmd test
npm.cmd run check:public
```

Эти проверки и `node smoke.mjs --local-only` не вызывают Gemini и Jev. Живой запуск `node smoke.mjs` расходует квоты и требует завершённой настройки. Успешные локальные проверки не подтверждают доступ к аккаунтам или остаток квоты.
