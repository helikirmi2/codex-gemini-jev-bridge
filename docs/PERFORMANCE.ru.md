# Настройки быстродействия

[English](PERFORMANCE.md) | [Русский](PERFORMANCE.ru.md)

Версия 1.1 уменьшает повторную передачу контекста и обращения к моделям. Gemini использует включённую квоту Google AI Pro через Antigravity CLI с `useG1Credits=false`. У Jev отдельная квота TypeSafe. Codex проверяет черновики и выполняет тесты.

## Выбор нужных строк

Оба инструмента, `delegate_task` и `jev_evaluate`, принимают `source_selections`:

```json
{
  "source_selections": [
    { "path": "C:/projects/example/src/parser.mjs", "start_line": 20, "end_line": 60 }
  ]
}
```

Замените пример абсолютным путём внутри разрешённых `sourceRoots`. Нумерация строк начинается с 1, обе границы включены. Фрагмент содержит исходный путь и диапазон строк. Завершающий перевод строки не создаёт дополнительную строку. Неверные диапазоны и выход за конец файла отклоняются, без усечения. Сохраняются проверки канонического пути, секретов, бинарных данных и размеров.

Прежний `files` выбирает целые файлы. Разные целые файлы можно совмещать с фрагментами; один канонический файл нельзя выбрать одновременно целиком и по строкам. Точные дубликаты отклоняются, разные диапазоны одного файла разрешены. Индексы источников начинаются с 0: сначала элементы `files`, затем `source_selections` в переданном порядке. Ограничения: до 20 выборок, 200 КБ на исходный файл, 600 КБ суммарно для уникальных исходных файлов и 600 КБ выбранного текста. Несколько диапазонов одного файла читаются из одного снимка за запрос.

## Узкие доказательства для Jev

`review_context` заменяет контекст подготовки только для Jev. Без него используется исходный `context`. Массив `review_evidence` должен содержать ровно один элемент на каждый критерий `review_checks`:

```json
{
  "task": "Propose a short explanation of the selected parser function.",
  "context": "Draft an explanation for a developer.",
  "source_selections": [
    { "path": "C:/projects/example/src/parser.mjs", "start_line": 20, "end_line": 60 }
  ],
  "review_checks": ["Every described branch is supported by the selected source."],
  "review_context": "Check factual support; do not claim tests were executed.",
  "review_evidence": [{ "source_indices": [0], "context": "Only this fragment supports the criterion." }],
  "response_mode": "compact"
}
```

Общие доказательства передаются один раз с привязкой критериев к индексам и дополнительному контексту. Невыбранные для проверки источники не попадают в запрос Jev. Явный пустой `source_indices` означает отсутствие исходных доказательств; отсутствие всего `review_evidence` передаёт все выбранные источники каждому критерию. Ошибочные индексы и число элементов проверяются до вызова Gemini. Задание, черновик и общий контекст проверки доступны всем критериям. Привязка задаётся инструкциями Jev и не является границей безопасности между вопросами. Нехватка доказательств или ошибка сервиса требует проверки Codex.

## Кэш и одновременные вызовы

Успешные точные запросы Gemini кэшируются в процессе MCP на 10 минут, до 20 записей. Ключ учитывает задание, выбранные тексты/диапазоны/пути, модель, путь CLI, инструкции и ограничения. Точные проверки Jev имеют такой же срок и до 100 записей. У каждого кэша бюджет 2 МБ сериализованных результатов; первыми удаляются старые записи. Обращение не продлевает срок хранения. Кэш хранится только в памяти, очищается при перезапуске и не сохраняет ошибки.

Профиль и запрет перерасхода проверяются перед каждым вызовом Gemini, включая попадания в кэш. Одновременные одинаковые задачи используют один запуск; разные получают ошибку занятости. Автоматической очереди, платного обхода и повторного использования диалога нет. Не повторяйте известные ошибки входа или квоты.

Antigravity использует [сохранение только отличий от настроек по умолчанию](https://www.antigravity.google/docs/settings?tab=cli). После собственного запуска CLI мост восстанавливает пропавший явный `useG1Credits=false`, сохраняя остальные актуальные настройки. Включённые кредиты или изменённые провайдеры/разрешения он отклоняет. Отсутствие флага перед новым запуском по-прежнему блокирует Gemini; восстановите его установщиком. Профиль глобальный и влияет на ручные сессии CLI.

## Короткий ответ и замеры

По умолчанию `response_mode=compact` возвращает превью из 400 символов, вердикт, выбор/уверенность по критериям, расход моделей и замеры времени/байтов. `result_file` содержит полный черновик, `metadata_file` — полный отчёт, включая вероятности и исходный расход. `response_mode=full` возвращает подробный отчёт и превью из 1600 символов. Для старых потребителей подробных полей указывайте `full`.

`cached` и `coalesced` различают кэш и объединённые вызовы. Повторно использованный результат Gemini имеет `provider_calls=0`, `current_usage=null` и исходную статистику в `original_usage`. Кэш Jev также означает ноль обращений и отсутствие текущего расхода; полный отчёт сохраняет прежний `usage`. Неизвестное число обращений при ошибке обозначается `null`. Не представляйте прежние токены как новый расход квоты.

`metrics` содержит время подготовки, генерации и проверки, объём исходников, доказательств/состояния Jev, результата и возвращаемого JSON без самого поля размера. Время измеряется до завершения проверки/сохранения черновика, перед записью итогового отчёта. Размер состояния Jev не включает инструкции вопросов и HTTP. Эти замеры не равны процентам квоты Google. `npm test` проверяет поведение локально. Живой `node smoke.mjs` проверяет первый запрос Gemini/Jev и точный повтор в одном процессе на вымышленных данных; к сервисам должен обратиться только первый.
